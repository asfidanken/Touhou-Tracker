This is an app to track progress across every official touhou game, including spinoffs and fighting games.
For each game you can insert 1CC status, Score, Lives, Bombs and extra limitations for each character and shot type.
On the "Overview" tab you can find grids for each game indicating which difficulty has been beaten with which character/shot type.
On the main tabs you can change Difficulty/Stage with the Left and Right arrow keys and scroll pages with the Up and Down arrow keys.
